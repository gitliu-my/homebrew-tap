# homebrew-tap

Homebrew tap for Git Liu apps and command-line tools.

## Install

```bash
brew install --cask gitliu-my/tap/agent-account-hub
```

Install csub on Apple Silicon macOS:

```bash
brew tap gitliu-my/tap
brew trust --formula gitliu-my/tap/csub
brew install gitliu-my/tap/csub
```

Upgrade csub:

```bash
brew update
brew upgrade csub
```
